# Skill: reel-blueprint

## Purpose
Plan exactly how to recreate the reference reel with the user's content. Every decision here maps directly back to what the reference does — nothing is invented. reel-capcut executes what blueprint decides.

All decisions stay in the conversation. No file written.

## Trigger
User runs `/reel-blueprint`.

## What to read BEFORE starting (read ALL of these)
1. Conversation context — the full reference analysis from `/reel-reference`
2. Conversation context — what the user's video is about (from their message after reel-reference)
3. `knowledge/hook-library.md` — hook types and compound hook construction
4. `knowledge/retention-playbook.md` — 4-phase structure, optimal length, loop close rules
5. `knowledge/viral-principles.md` — signal hierarchy, DM share test, caption/SEO strategy
6. `knowledge/text-design-system.md` — safe zones, fonts, color, kinetic captions, export specs

Do not start writing until all files are read.

## What to do

Every step starts with: **what does the reference do here?** Then: **how does the user's content recreate that?**

---

### Step 1 — Hook

From the reference analysis:
- What hook type does the reference use? (from hook-library.md)
- What compound combination fires together?
- What is the exact first frame visual in the reference?

Now for the user's content:
- Write the **exact hook line** for the user's video — the actual words, not a template
- Describe the **first frame visual** — what the user shoots in frame 1 to match the reference's hook energy
- State whether a zoom-in is used — only if the reference uses one
- Write the **caption first line** that escalates the hook

Self-test: "Would this stop my own scroll?" If uncertain → rewrite.

---

### Step 2 — Structure map

The reference has a structure. Map the user's clips onto that exact structure.

```
[0–3s]    HOOK
  Visual: [which of the user's clips / what moment]
  Text: [exact text, or "none"]
  Hook mechanism: [what fires — from the reference's hook formula]

[3–7s]    ESCALATION
  Visual: [which clip, what moment]
  Text: [if any]
  Emotional move: [what the reference builds here — replicate it]

[7–Xs]    VALUE DELIVERY
  [3–4s window]: [user's clip] → text "[text]" → visual reset: [what changes]
  [3–4s window]: [user's clip] → text "[text]" → visual reset: [what changes]
  [... every window — match the reference's rhythm exactly]

[Midpoint Xs]  MIDPOINT INTERRUPT
  What form: [match what the reference does here]
  Exact moment: [Xs]

[Final Xs]  CLOSE
  Type: [match the reference — loop / CTA / emotional punctuation]
  If loop: how the user's ending connects back to their opening
  If CTA: exact text
```

Counter-trend check: if the reference is raw/authentic, do NOT add hyper-editing. Match the reference's energy exactly.

---

### Step 3 — Text design

Copy the reference's text system exactly. For each text element:

```
Text element [N]:
  Content: "[exact words for the user's video]"
  Font: [what the reference uses — name + weight]
  Color: [hex — match the reference]
  Contrast method: [stroke / shadow / box — match the reference + color + thickness]
  Position: [match reference — horizontal alignment + vertical px from top]
  Duration: [start]s → [end]s
  Animation: [match reference — word-by-word kinetic / fade / pop / none]
  Safe zone: [confirmed clear of bottom 280px / right 90px / top 150px]
```
