## WHAT MAKES A HOOK WORK

Effective hooks exploit **pattern interrupts** — unexpected visuals, contrarian statements, or curiosity gaps that force the brain to shift from passive to active attention.

The most powerful hooks tap into one or more of these psychological drivers:

---

## THE 6 HOOK TYPES

### 1. Curiosity (Information Gap)
Creates an itch the brain can only scratch by watching.
```
"The trick no one tells you about..."
"I finally figured out why your [X] keeps failing..."
"What nobody mentions about [topic]..."
```

### 2. The Negative Callout
Triggers loss aversion (psychologically stronger than gain anticipation).
```
"This is the mistake keeping your [X] from [desired outcome]..."
"Stop doing [X] — here's why it's hurting you..."
"This mistake cost me $50K... and you're making it right now."
```

### 3. The Tension / Gatekeep
Creates exclusivity pressure.
```
"Stop scrolling if you want to fix your..."
"The one thing keeping you from [outcome]..."
"If you're not doing this, you're leaving [X] on the table."
```

### 4. The Value Promise (Specificity is the key)
The more specific the number or outcome, the more credible and stoppable.
```
"The exact framework I used to [specific result with numbers]..."
"3 things I'd tell myself before [starting X]..."
"This took me 2 years to learn — you can get it in 60 seconds."
```

### 5. The Contrarian / Controversy
Challenges existing beliefs. Forces engagement.
```
"Everything you know about [X] is wrong."
"[Popular advice] is actually terrible. Here's why."
"I used to believe [X]. I was dead wrong."
```

### 6. The Vulnerability Hook (2026 — growing in power)
Disarms the scroll reflex. Signals authenticity.
```
"I almost didn't post this because..."
"Here's a mistake that cost me [loss]..."
"I've been thinking about this and I might be wrong, but..."
"I've been doing this wrong for 2 years."
```
This is the "anti-hook hook." In a feed full of polished brand content, vulnerability is the pattern interrupt.

---

## COMPOUND HOOKS (Most Powerful)

Combine 2+ hook types. Creates a hook that's nearly impossible to scroll past.

```
"This $50K mistake [curiosity + negative callout]
is something 90% of you are making right now [social proof + fear]."
```

```
"I almost didn't post this [vulnerability]
because this is the mistake keeping your Reels from going viral [negative callout + curiosity]."
```

## VISUAL HOOK TECHNIQUES

The first frame IS the hook. If the thumbnail is boring, the scroll doesn't stop.

- **Start mid-action** — never from a static position
- **1.2x digital zoom-in on frame one** — creates a snap of visual energy (note: by 2026 this is becoming the baseline — standing completely still is becoming the NEW pattern interrupt in saturated niches)
- **Show the "after" first** — show the transformation/result before explaining the process
- **Bold contrasting text overlay** — complements the spoken hook for mute viewers
- **High contrast, slightly saturated first frame** — your Reel competes with 1,000+ in the feed

---

## HOOK + CAPTION PAIRING

The hook in the video and the first line of the caption work together. The caption's first line should extend or escalate the hook (not repeat it) to trigger the "...more" tap.

**Example:**
- Video hook: "This mistake cost me $50K..."
- Caption first line: "And I almost didn't catch it until it was too late — here's the 4th sign that most people miss entirely..."

---

## WHAT NEVER WORKS

- "Hey guys, today I'm going to show you..." — slow intro = immediate drop-off
- Starting from a standing/sitting static position with no movement
- Stating the topic before creating curiosity: "Today I'm going to talk about Instagram growth..."
- Generic openings that give the viewer no reason to stop scrolling

---

## HOW TO USE THIS IN REEL-BLUEPRINT

When writing the hook for a specific video:
1. Pick the **primary hook type** that matches the video's emotional angle
2. Add a **secondary hook type** to make it compound if possible
3. State the hook in 1–2 sentences max — no setup
4. Verify: "Would this stop MY scroll?"
5. Pair with a visual hook technique for the first frame
6. Write the caption first line to escalate (not repeat) the video hook
